## 关键决策

**artifact 不经过模型。** 这是整个协议的立命之本 ——
它从工具直接流到 SSE 与响应体，模型换个说法不会让调用方的解析崩掉。
验收方式就是**改模型文案、断言 artifact 不变**。

**排序必须在截断之前。** 先截断再排序，「最便宜的」变成「前 5 条里最便宜的」——
这是个会给出错误答案却不报错的 bug，必须有用例钉住。

**安全规则只提供「追加」接口。** 不提供替换，同 id 的租户规则被忽略而非覆盖 ——
允许覆盖等价于允许放宽（把 block 改成 mask 就绕过去了）。

## 风险处置

| 风险 | 处置 |
|---|---|
| artifact 与 content 不一致 | 两者同源：由同一份计算结果分别渲染，不各算各的 |
| 列表撑爆 SSE 帧 | 条数封顶 20，截断时**必须置 `truncated`** |
| 正则存 JSONB 变成 `{}` | 存 source + flags，读时重建；用例验证往返 |
| 租户配置每请求查库 | 进程内缓存，写入即失效（不设 TTL） |
